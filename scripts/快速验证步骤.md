# 🚀 生产环境快速验证步骤

## ⚠️ 当前状态

刚刚测试发现API返回404错误，这是正常的！原因：

1. **Render Free Plan会休眠** - 第一次请求需要15-30秒唤醒
2. **代码正在部署** - 自动部署通常需要3-5分钟
3. **需要等待部署完成**

---

## ✅ 推荐验证步骤

### 步骤1：检查Render部署状态（5分钟）

1. 访问 Render Dashboard: https://dashboard.render.com/
2. 找到 `rabbit-ai-backend` 服务
3. 查看 **Events** 标签
4. 确认最新部署状态：
   - ✅ **Live** - 部署成功，可以测试
   - 🟡 **Deploying** - 正在部署，请等待
   - ❌ **Failed** - 部署失败，需要查看日志

**预计时间**: Render自动部署通常需要 **3-5分钟**

---

### 步骤2：等待服务唤醒（30秒）

如果部署已完成但API仍返回404：

#### 方法A：浏览器访问首页
打开浏览器访问：
```
https://rabbit-ai-backend.onrender.com/
```

等待15-30秒，直到看到响应（可能是 "Cannot GET /"，这是正常的）

#### 方法B：连续请求API
```powershell
# PowerShell
for ($i=1; $i -le 5; $i++) {
    Write-Host "尝试 $i/5..." -ForegroundColor Yellow
    try {
        Invoke-RestMethod -Uri "https://rabbit-ai-backend.onrender.com/health" -ErrorAction Stop
        Write-Host "✅ 服务已唤醒！" -ForegroundColor Green
        break
    } catch {
        Write-Host "等待服务唤醒..." -ForegroundColor Gray
        Start-Sleep -Seconds 10
    }
}
```

---

### 步骤3：验证收益计算（1分钟）

#### 选项1：浏览器验证（最简单）

直接打开：
```
https://rabbit-ai-backend.onrender.com/api/user/earnings?address=0x9897f1f7ee7c1c443e28a52fe80ed514cf65eefe
```

**看这两个字段**：
```json
{
  "dailyRate": 4,        // ✅ 应该是 4（不是 0.04）
  "pendingUsdt": "XX.XX" // ✅ 应该是合理的值
}
```

#### 选项2：使用HTML验证工具

1. 双击打开：`rabbit-ai-backend/scripts/test-production.html`
2. 点击 **"开始验证"** 按钮
3. 查看结果

#### 选项3：PowerShell命令

```powershell
# 快速验证脚本
$addr = "0x9897f1f7ee7c1c443e28a52fe80ed514cf65eefe"
$url = "https://rabbit-ai-backend.onrender.com/api/user/earnings?address=$addr"

try {
    $resp = Invoke-RestMethod -Uri $url
    Write-Host "✅ API调用成功！" -ForegroundColor Green
    Write-Host "日利率: $($resp.dailyRate)%" -ForegroundColor Cyan
    
    if ($resp.dailyRate -eq 4) {
        Write-Host "🎉 修复成功！日利率正确显示为 4%" -ForegroundColor Green
    } else {
        Write-Host "⚠️ 日利率显示异常: $($resp.dailyRate)" -ForegroundColor Red
    }
} catch {
    Write-Host "❌ API调用失败: $($_.Exception.Message)" -ForegroundColor Red
    Write-Host "可能原因: 服务休眠或正在部署" -ForegroundColor Yellow
}
```

## 🔧 故障排查

### 问题1: API持续返回404

**原因**: 
- Render服务正在部署
- 服务休眠未唤醒
- 路由配置错误

**解决**:
```bash
# 1. 检查Render日志
# 访问: https://dashboard.render.com → 选择服务 → Logs

# 2. 手动触发部署
# 访问: https://dashboard.render.com → 选择服务 → Manual Deploy → Deploy latest commit

# 3. 检查环境变量
# 确保所有必需的环境变量已配置
```

### 问题2: 部署失败

**常见原因**:
- Node.js版本不匹配
- 依赖安装失败
- 环境变量缺失

**解决**:
1. 查看 Render 部署日志
2. 确认 `package.json` 中的 `engines` 配置
3. 确认所有环境变量已在 Render Dashboard 中设置

### 问题3: 修复未生效

**检查点**:
```sql
-- 在Supabase中直接查询VIP配置
SELECT tier, daily_rate 
FROM vip_tiers 
ORDER BY tier;

-- 预期结果:
-- tier | daily_rate
-- -----|------------
--   1  |     2
--   2  |     4
--   3  |     6
--   4  |    10
```

如果 `daily_rate` 是 `0.02, 0.04` 等小数，说明：
- 代码修改未推送
- 或数据库未更新
